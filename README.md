# 📋 Sistema de Planificación y Rendición de Actividades

Sistema web para crear actividades, elaborar presupuestos, registrar gastos, rendir cuentas y generar reportes.

## 🚀 Cómo usar

1. Abre el archivo `index.html` en tu navegador
2. Listo. No necesitas instalar nada

## ✨ Funcionalidades

- ✅ Crear, editar y eliminar actividades
- ✅ Elaborar presupuestos con items dinámicos
- ✅ Registrar gastos ejecutados
- ✅ Seleccionar metas de la actividad
- ✅ Control de estados:
  - 📝 Borrador
  - 🔍 En Revisión
  - ✅ Aprobada
  - 🚀 Ejecutada
  - 💰 Rendida
  - 🔒 Cerrada
- ✅ Dashboard con estadísticas en tiempo real
- ✅ Generar reporte PDF profesional
- ✅ Exportar a Excel (CSV)
- ✅ Datos guardados en el navegador (localStorage)
- ✅ Diseño responsive (funciona en celular y tablet)
- ✅ Sin base de datos
- ✅ Sin servidor
- ✅ Sin instalación
