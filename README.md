# 📋 Sistema de Planificación y Rendición de Actividades

Sistema web para crear actividades, elaborar presupuestos, registrar gastos, rendir cuentas y generar reportes.

## 🚀 Cómo usar

1. Abre el archivo `index.html` en tu navegador
2. Listo. No necesitas instalar nada

## ✨ Funcionalidades

- ✅ Crear, editar y eliminar actividades
- ✅ Elaborar presupuestos con items dinámicos
- ✅ Registrar gastos ejecutados
- ✅ Seleccionar metas de la actividad
- ✅ Control de estados:
  - 📝 Borrador
  - 🔍 En Revisión
  - ✅ Aprobada
  - 🚀 Ejecutada
  - 💰 Rendida
  - 🔒 Cerrada
- ✅ Dashboard con estadísticas en tiempo real
- ✅ Generar reporte PDF profesional
- ✅ Exportar a Excel (CSV)
- ✅ Datos guardados en el navegador (localStorage)
- ✅ Diseño responsive (funciona en celular y tablet)
- ✅ Sin base de datos
- ✅ Sin servidor
- ✅ Sin instalación

## 🎯 Flujo de una Actividad
Crear → Planificar → Presupuestar → Aprobar → Ejecutar → Rendir → Cerrar



## 📊 Dashboard

El panel principal muestra:

- Total de actividades
- Presupuesto aprobado
- Gasto ejecutado
- Ahorro o excedente
- Últimas actividades registradas

## 💰 Presupuesto y Gastos

- Tabla dinámica para agregar items
- Cálculo automático de subtotales
- Comparación presupuesto vs ejecutado
- Control de comprobantes

## 📄 Reportes

- **PDF**: Reporte profesional con resumen, detalle y firmas
- **Excel**: Archivo CSV con todas las actividades

## 🔒 Privacidad

Todos los datos se guardan en el navegador del usuario (localStorage). No se envía ninguna información a servidores externos.

## 📱 Responsive

El sistema se adapta a diferentes tamaños de pantalla:

- 🖥️ Escritorio
- 💻 Laptop
- 📱 Tablet
- 📱 Celular
